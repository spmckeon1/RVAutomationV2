# Dependencies

## Purpose

This document records all external software dependencies required to build, run, and maintain the RVAutomation system.

The intent is that a new Raspberry Pi can be configured from scratch by following this document. Every installed package should have a documented purpose. Dependencies should be kept to a minimum and only introduced when they provide clear value to the project.

This document includes:

- Node-RED palette modules
- Operating system packages
- Development tools
- Runtime software
- Version information (where appropriate)
